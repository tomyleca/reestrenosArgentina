
## Llamada a api

La api key para tmdb no tiene llamadas ilimitadas, por lo que si se usa en test, estos deben estar marcados como integration y se debe tener configurado siempre que sean excluidos al correr todos los test y solo puedan ser corridos individualmente.

## Implementar cine

Cada vez que te paso los datos de un cine para implementarlo tenes que hacer su scrapper y su api requester. No te olvides de agregar los test para ambos. No te olvides de agregar los test para ambos. Recorda que dentro de ambos test se debe chequear que efectivamente se esten trayendo peliculas.
