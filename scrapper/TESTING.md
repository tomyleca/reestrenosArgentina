# Ejecutar tests del scraper

## Estructura de tests

Los tests se encuentran en la carpeta `tests/` en la raíz del proyecto.
Las capturas de pantalla generadas durante los tests se guardan en `tests/screenshots/`.

## Comandos

```bash
# Una sola vez (sin watch mode)
npm test -- --run

# Con interfaz gráfica
npm run test:ui

# En modo watch (re-ejecuta al guardar cambios)
npm test
```
